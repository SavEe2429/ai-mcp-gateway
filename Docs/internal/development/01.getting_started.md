# 01. Getting Started

## Prerequisites

- Python `3.14+`
- [`uv`](https://docs.astral.sh/uv/) package manager
- Git
- *(Optional)* Tailscale CLI installed and logged in for external Funnel access

## Clone and Install

```bash
git clone https://github.com/SavEe2429/ai-mcp-gateway.git
cd ai-mcp-gateway
uv sync --dev
```

## Install Git Hooks

```bash
uvx pre-commit install
uvx pre-commit install --hook-type commit-msg
```

## Run Locally

```bash
# Console entrypoint
uv run ai-mcp-gateway

# Or package module entrypoint
uv run python -m ai_mcp_gateway
```

The server binds to `0.0.0.0:3000` by default and opens the local dashboard at `http://localhost:3000/ui`.
