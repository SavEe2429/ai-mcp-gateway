# 05. Deployment & Release Packaging

## Local Distribution Builds

### Python Wheel & Source Archive

```bash
uv build --out-dir dist/
```

### Windows Binary Distribution (PyInstaller)

```bash
# Directory bundle (onedir - recommended)
uv run python packaging/build.py --mode onedir

# Single standalone executable (onefile)
uv run python packaging/build.py --mode onefile
```

The generated `.spec` file (`packaging/ai-mcp-gateway.spec`) is placed inside `packaging/` via
`--specpath` (ignored by `*.spec` in `.gitignore`), intermediate build files go to
`build/ai-mcp-gateway/`, and final binaries are written to `out/ai-mcp-gateway/`.

## Automated GitHub Release Pipeline

`.github/workflows/release.yml` runs on pushes to `release/v*` branches or manual
`workflow_dispatch`:

1. Validates lint (`ruff`) and tests (`pytest`).
2. Synchronizes `pyproject.toml` version and promotes `CHANGELOG.md` + `Docs/public/release-notes/`.
3. Builds Python distributions (`.whl`, `.tar.gz`) on Ubuntu and `ai-mcp-gateway-windows-x64.zip`
   (`onedir` bundle) on `windows-latest`.
4. Generates `SHA256SUMS.txt` and publishes the GitHub Release.
