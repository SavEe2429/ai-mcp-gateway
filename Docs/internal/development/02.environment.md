# 02. Environment & Configuration

## Single Source of Truth (SSOT)

Application settings are defined in `config/config.yaml` and validated strictly at startup by Pydantic models in `src/ai_mcp_gateway/model/config.py`.

## Path Resolution Hierarchy

`src/ai_mcp_gateway/utils/config.py` separates read-only bundled assets from writable runtime paths so both source execution and standalone PyInstaller `.exe` builds behave identically:

1. **Configuration file (`find_config_yaml`)**:
   - Explicit argument (`custom_path`)
   - `GATEWAY_CONFIG_PATH` environment variable
   - `<runtime_dir>/config/config.yaml` (next to the `.exe` or project root)
   - `<cwd>/config/config.yaml`
   - Bundled fallback inside `_MEIPASS` when frozen
2. **Writable runtime directories**:
   - `GATEWAY_DATA_DIR`, `GATEWAY_DB_PATH`, `GATEWAY_WORKSPACE_DIR`, `GATEWAY_CLIENT_SECRET_FILE` override defaults when set.
   - Otherwise, relative paths resolve against `get_runtime_dir()` (the executable directory when frozen, or repository root in source mode).

## Credentials

- `MCP_CLIENT_ID` overrides `auth.client_id` (`local-mcp` by default).
- `MCP_CLIENT_SECRET` or `GATEWAY_SECRET_KEY` overrides `auth.client_secret`. When omitted, a cryptographically random secret is generated and persisted in `data/client_secret.key`.
