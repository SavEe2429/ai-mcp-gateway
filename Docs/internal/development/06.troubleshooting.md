# 06. Troubleshooting

## Common Issues

### 1. Tailscale Funnel Fails to Start
- **Symptom**: Console prints `[Tailscale] Unable to query status` or `DNSName unavailable`.
- **Resolution**: Ensure the Tailscale desktop client is signed in and MagicDNS + Funnel are enabled on your tailnet. For local-only testing, set `server.enable_tailscale_funnel: false` in `config/config.yaml`.

### 2. Dashboard Returns `403 Forbidden`
- **Symptom**: Accessing `/ui` or `/api/ui/state` returns `403`.
- **Resolution**: The dashboard is intentionally locked to localhost (`127.0.0.1`, `::1`). Do not access `/ui` through the public Tailscale Funnel URL or external reverse-proxy `X-Forwarded-*` headers.

### 3. `.exe` Fails to Persist Database or Workspace
- **Symptom**: State resets on restart.
- **Resolution**: Place `ai-mcp-gateway.exe` in a writable directory (not a read-only folder such as `Program Files`). Verify `data/gateway.db` and `workspace/` are created beside the executable.

### 4. Commit Rejected by `commit-msg` Hook
- **Symptom**: `pre-commit` rejects a commit message.
- **Resolution**: Prefix commit subjects with an allowed Conventional Commit type (`feat`, `fix`, `docs`, `style`, `refactor`, `perf`, `test`, `build`, `ci`, `chore`, `revert`).
