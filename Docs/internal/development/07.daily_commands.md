# 07. Daily & All Commands Reference

Quick copy-paste command cheatsheet for day-to-day development, testing, security scanning,
packaging, and releasing `ai-mcp-gateway`.

---

## 1. Run Gateway

```bash
# Start gateway via registered CLI entrypoint
uv run ai-mcp-gateway

# Start gateway via Python module
uv run python -m ai_mcp_gateway

# Check Tailscale Funnel status (optional external HTTPS)
tailscale status
tailscale funnel status
```

---

## 2. Environment & Dependencies

```bash
# Sync runtime + dev dependencies from uv.lock
uv sync --dev

# Verify lockfile matches pyproject.toml
uv lock --check

# Update lockfile after changing dependencies
uv lock
```

---

## 3. Lint, Format & Docs

```bash
# Ruff lint check
uv run ruff check src/ tests/ packaging/ templates/ .github/scripts/release/

# Ruff lint auto-fix + format
uv run ruff check --fix src/ tests/ packaging/ templates/ .github/scripts/release/
uv run ruff format src/ tests/ packaging/ templates/ .github/scripts/release/

# Ruff format check only (CI parity)
uv run ruff format --check src/ tests/ packaging/ templates/ .github/scripts/release/

# Markdown lint & Prettier formatting checks (optional Node.js tools)
npx markdownlint-cli2 "Docs/**/*.md" "README.md" "CHANGELOG.md" "CONTRIBUTING.md" "SECURITY.md"
npx prettier --ignore-path .gitignore --check "**/*.{md,yaml,yml,json}"

# MkDocs documentation preview & strict build check
uvx --with mkdocs-material mkdocs serve
uvx --with mkdocs-material mkdocs build --strict
```

---

## 4. Tests

```bash
# Full pytest suite
uv run pytest

# Verbose pytest on a single test file
uv run pytest tests/integration/test_oauth_flow.py -vv

# Python standard unittest runner (CI parity)
uv run python -m unittest discover tests
```

---

## 5. Security & Secret Scanning

```bash
# Scan full git commit history for leaked secrets (Gitleaks)
gitleaks git --redact -v --no-banner .

# Scan staged changes before committing
gitleaks git --pre-commit --redact --staged --verbose --no-banner

# Scan working directories (source, tests, docs)
gitleaks dir --redact -v --no-banner src tests Docs

# Run all pre-commit hooks manually across all files
pre-commit run --all-files
```

---

## 6. Build & Packaging

```bash
# Windows standalone directory bundle (recommended -> out/ai-mcp-gateway/, spec -> packaging/)
uv run python packaging/build.py --mode onedir

# Windows single-file executable
uv run python packaging/build.py --mode onefile

# Python wheel & source distribution (-> dist/)
uv build --out-dir dist/
```

---

## 7. Git & Release Workflow

```bash
# Install local pre-commit + commit-msg hooks (one-time per clone)
pre-commit install --install-hooks
pre-commit install --hook-type commit-msg

# Feature branch & PR workflow
git checkout -b feat/short-description
git add -A
git commit -m "feat(scope): concise summary"
git push -u origin feat/short-description

# Trigger automated release workflow (e.g. v1.1.0) from updated main
git checkout main
git pull origin main
git checkout -b release/v1.1.0
git push -u origin release/v1.1.0
```
