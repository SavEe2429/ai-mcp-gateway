# Templates Directory (`templates/`)

Standardized code templates used when authoring new modules in this repository.

## Contents

- `python/script_template.py`: Canonical 9-section Python module layout (`STANDARD LIBRARY IMPORTS`,
  `THIRD-PARTY IMPORTS`, `LOCAL APPLICATION/LIBRARY-SPECIFIC IMPORTS`, `CONSTANTS`, `ENUMS`,
  `CLASS DEFINITIONS`, `PUBLIC FUNCTIONS`, `PRIVATE FUNCTIONS`, `MAIN EXECUTION`).

## Usage

Copy `templates/python/script_template.py` when creating new Python modules under
`src/ai_mcp_gateway/` to preserve consistent section ordering and docstrings.
