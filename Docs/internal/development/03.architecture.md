# 03. Architecture & Coding Standards

## Package Layout

- `src/ai_mcp_gateway/`: Core Python package (`src/` layout).
- `tests/unit/` and `tests/integration/`: Partitioned, hermetic test suite.
- `packaging/`: PyInstaller build script targeting `out/ai-mcp-gateway/`.
- `config/`: Default `config.yaml` configuration.

## Module Standards

1. **9-Section Template**: Python modules follow `templates/python/script_template.py` (`(01)` stdlib imports through `(09)` main execution).
2. **Granular Exception Handling**: Domain subroutines catch explicit exception types (`OSError`, `ValueError`, `sqlite3.Error`, `MCPError`, etc.) rather than broad `except Exception:` blocks.
3. **Workspace Sandboxing**: Every workspace path resolves via `tools.filesystem.safe_path()` using `os.path.realpath` and `os.path.commonpath` to block traversal and symlink/junction escapes.
4. **Localhost Dashboard Isolation**: `interfaces.middleware.shield.check_localhost_dashboard_guard` restricts `/ui`, `/api/ui/*`, and `/ws/ui` to localhost and rejects cross-origin/proxied requests with `403 Forbidden`.
5. **Strict LF Endings**: All text, code, and Markdown files enforce `\n` line endings via `.gitattributes` and `.editorconfig`.
