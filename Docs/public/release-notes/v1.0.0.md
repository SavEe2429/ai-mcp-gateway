# Release Notes - v1.0.0

Initial public release of `ai-mcp-gateway`.

### Highlights
- **MCP Streamable HTTP (`POST /mcp`)**: Protocol `2024-11-05+` support with automatic session recovery and `/sse` compatibility rewrite.
- **OAuth 2.0 / 2.1 + PKCE (`S256`)**: RFC 8414 and RFC 9728 metadata discovery, persistent auto-generated client secrets, and multi-AI client recognition (Google Gemini, Anthropic Claude, OpenAI ChatGPT, Cursor).
- **Web Dashboard (`/ui`)**: Localhost-locked control center featuring live Activity Logs, Developer Traffic Inspector, Human-in-the-Loop (HITL) approval queue, External MCP Client Hub, and Security Shield / Banned IPs management.
- **Sandboxed Tools**: Workspace-confined filesystem tools (`safe_path`), terminal command runner with auto-background task management, and desktop/window capture tools.
- **Windows Binary Distribution (`onedir`)**: Packaged Windows bundle (`ai-mcp-gateway-windows-x64.zip` containing `ai-mcp-gateway.exe` and `_internal/`) storing persistent `data/` and `workspace/` alongside the executable.
