# 01. Getting Started (Zero-to-Ready Setup)

Complete step-by-step guide to go from a clean machine to running, testing, linting, and
committing in `ai-mcp-gateway`.

---

## 1. Install Base System Tools

### Windows (PowerShell)

```powershell
# 1. Git
winget install --id Git.Git -e

# 2. uv (manages Python 3.14+ and virtual environments automatically)
winget install --id astral-sh.uv -e
# Or official installer:
# powershell -ExecutionPolicy ByPass -c "irm https://astral.sh/uv/install.ps1 | iex"

# 3. Gitleaks (required by the gitleaks-system pre-commit hook and secret scans)
winget install --id Gitleaks.Gitleaks -e

# 4. (Optional) Node.js LTS — for external Node.js MCP servers, markdownlint, and prettier
winget install --id OpenJS.NodeJS.LTS -e

# 5. (Optional) Tailscale CLI — for exposing /mcp over HTTPS Funnel
winget install --id Tailscale.Tailscale -e
```

Restart your terminal so updated `PATH` entries take effect, then install Python `3.14` and
`pre-commit` via `uv`:

```powershell
uv python install 3.14
uv tool install pre-commit
uv tool update-shell
```

### macOS

```bash
# Homebrew packages
brew install git uv gitleaks
# Optional: Node.js LTS & Tailscale
brew install node
brew install --cask tailscale

# Python 3.14 & pre-commit
uv python install 3.14
uv tool install pre-commit
uv tool update-shell
```

### Linux (Debian / Ubuntu)

```bash
# Base utilities & Git
sudo apt-get update && sudo apt-get install -y git curl tar

# uv
curl -LsSf https://astral.sh/uv/install.sh | sh
export PATH="$HOME/.local/bin:$PATH"

# Python 3.14 & pre-commit
uv python install 3.14
uv tool install pre-commit
uv tool update-shell

# Gitleaks v8.30.1 (x64 with SHA-256 verification)
curl -fsSL -o /tmp/gitleaks.tar.gz "https://github.com/gitleaks/gitleaks/releases/download/v8.30.1/gitleaks_8.30.1_linux_x64.tar.gz"
echo "551f6fc83ea457d62a0d98237cbad105af8d557003051f41f3e7ca7b3f2470eb  /tmp/gitleaks.tar.gz" | sha256sum -c -
sudo tar -xzf /tmp/gitleaks.tar.gz -C /usr/local/bin gitleaks
rm -f /tmp/gitleaks.tar.gz
```

### Verify Installed CLI Tools

Open a fresh terminal (so `PATH` updates from `uv tool update-shell` are loaded) and confirm:

```bash
git --version
uv --version
gitleaks version
pre-commit --version
```

## 2. Configure Git Identity (Recommended Before First Commit)

To avoid exposing a personal email address in Git history, enable GitHub's noreply email settings
and configure Git locally or globally:

```bash
git config --global user.name "<your-github-username>"
git config --global user.email "<your-github-username>@users.noreply.github.com"
```

---

## 3. Clone Repository & Sync Project Virtual Environment

`ruff`, `pytest`, `pyinstaller`, and `httpx` are pinned in `pyproject.toml` / `uv.lock` and
installed automatically inside `.venv/` by `uv sync --dev` (no global `pip install` needed):

```bash
git clone https://github.com/SavEe2429/ai-mcp-gateway.git
cd ai-mcp-gateway
uv sync --dev

# Verify project-local dev tools inside .venv
uv run ruff --version
uv run pytest --version
```

_(Optional)_ Copy `.env.example` to `.env` if you want local environment overrides:

```bash
cp .env.example .env
```

---

## 4. Install & Verify Git Hooks

Activate both pre-commit checks (whitespace, YAML/TOML/JSON, private-key check, `ruff`,
`gitleaks-system`) and Conventional Commit validation (`commit-msg`):

```bash
pre-commit install --install-hooks
pre-commit install --hook-type commit-msg

# Optional: verify hooks pass against current repository files
pre-commit run --all-files
```

## 5. Optional Docs & Markdown Tooling

The repository ships configs for Markdown linting (`.markdownlint.yaml`), formatting
(`.prettierrc.yaml`), and MkDocs documentation (`mkdocs.yml`).

- **Node.js `markdownlint-cli2` & `prettier`**:

  ```bash
  # Run on demand via npx (or install globally with: npm install -g markdownlint-cli2 prettier)
  npx markdownlint-cli2 "Docs/**/*.md" "README.md" "CHANGELOG.md" "CONTRIBUTING.md" "SECURITY.md"
  npx prettier --ignore-path .gitignore --check "**/*.{md,yaml,yml,json}"
  ```

  _(In VS Code, installing the `DavidAnson.vscode-markdownlint` extension applies
  `.markdownlint.yaml` automatically while editing.)_

- **MkDocs Live Preview**:

  ```bash
  uvx --with mkdocs-material mkdocs serve
  ```

## 6. First-Run Smoke Test & Local Launch

1. Run the automated verification suite first (uses hermetic temporary storage, never modifies
   `data/` or `workspace/`):

   ```bash
   uv run ruff check src/ tests/ packaging/ templates/ .github/scripts/release/
   uv run pytest
   ```

2. Launch the gateway locally:

   ```bash
   # Console entrypoint
   uv run ai-mcp-gateway

   # Or package module entrypoint
   uv run python -m ai_mcp_gateway
   ```

3. On startup:
   - The gateway acquires `data/gateway.lock` (blocking a second concurrent instance), initializes
     `data/gateway.db`, creates `data/client_secret.key`, and masks `Client Secret` in the terminal.
   - If Tailscale is not installed or signed in yet, the gateway falls back cleanly to local mode (or
     set `server.enable_tailscale_funnel: false` in `config/config.yaml`).
   - Your browser opens `http://localhost:3000/ui` with the **Select Workspace** modal ready to
     confirm or browse your working folder.
