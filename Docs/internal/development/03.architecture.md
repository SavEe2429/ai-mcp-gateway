# 03. Architecture & Coding Standards

## Package Layout

- `src/ai_mcp_gateway/`: Core Python package (`src/` layout).
- `tests/unit/` and `tests/integration/`: Partitioned, hermetic test suite.
- `packaging/`: PyInstaller build script targeting `out/ai-mcp-gateway/`.
- `config/`: Default `config.yaml` configuration.

## Module Standards

1. **9-Section Template**: Python modules follow `templates/python/script_template.py` (`(01)`
   stdlib imports through `(09)` main execution).
2. **Granular Exception Handling**: Domain subroutines catch explicit exception types (`OSError`,
   `ValueError`, `sqlite3.Error`, `MCPError`, etc.) rather than broad `except Exception:` blocks.
3. **Workspace Sandboxing & Secret Protection**: Every workspace path resolves via
   `tools.filesystem.safe_path()` using `os.path.realpath` and `os.path.commonpath` to block
   traversal, symlink/junction escapes, gateway `data/` files (`gateway.db`, `client_secret.key`,
   `gateway.lock`), and `.env` files (preserving `.env.example`, `.env.sample`, `.env.template`).
4. **Localhost Dashboard Isolation**: `interfaces.middleware.shield.check_localhost_dashboard_guard`
   restricts `/ui`, `/api/ui/*`, and `/ws/ui` to localhost and rejects cross-origin/proxied requests
   with `403 Forbidden`.
5. **Single-Instance Process Lock**: `core.instance_lock.SingleInstanceLock` holds an OS-enforced
   non-blocking lock on `data/gateway.lock` so two gateway processes cannot run simultaneously.
6. **Secret Scanning & Pre-Commit Hygiene**: `.pre-commit-config.yaml` (`gitleaks-system`) and
   `.github/workflows/ci.yml` (`gitleaks git`) enforce automated secret detection across commits.
7. **Strict LF Endings**: All text, code, and Markdown files enforce `\n` line endings via
   `.gitattributes` and `.editorconfig`.
