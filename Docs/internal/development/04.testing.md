# 04. Testing & Quality Verification

## Hermetic Test Environment

`tests/__init__.py` and `tests/conftest.py` configure `GATEWAY_DATA_DIR`, `GATEWAY_DB_PATH`, `GATEWAY_WORKSPACE_DIR`, and `GATEWAY_CLIENT_SECRET_FILE` inside an ephemeral temporary directory before importing `ai_mcp_gateway.main`. Test runs never mutate or read your local `data/gateway.db` or `workspace/`.

## Quality Gate Commands

```bash
# 1. Static analysis & import sorting
uv run ruff check src/ tests/ packaging/ .github/scripts/release/

# 2. Full unit + integration test suite
uv run pytest

# 3. Standard unittest runner
uv run python -m unittest discover tests

# 4. Lockfile consistency check
uv lock --check
```

## CI Parity

`.github/workflows/ci.yml` executes the exact same 4 verification tiers on every push and pull request targeting `main` or `master`.
